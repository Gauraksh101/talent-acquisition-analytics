# Talent Acquisition Analytics Dashboard
Complete recruitment analytics project using SQL, Python and Power BI to analyze hiring performance and recruiter efficiency.

## 📊 Project Overview
Built an end-to-end recruitment analytics solution analyzing 100+ candidates to reduce time-to-hire and improve source effectiveness.

## 🔧 Tech Stack
- Python (Pandas, NumPy) for data cleaning
- SQL for hiring insights
- Power BI for visualization

### 📊 Key KPIs
- Total Hired: 55
- Top Recruiter: Priya (19 Hires)
- Fastest Hiring Source: Indeed - 20.14 days
- Slowest Hiring Source: LinkedIn - 22.16 days

### 🔍 Key Insights
1. Priya is top performing recruiter with 19 hires
2. Indeed hires fastest (20 days), LinkedIn takes longest (22 days) due to extra screening
3. Referral and Naukri are balanced at 21 days average
