# talent-acquisition-analytics
Talent Acquisition Analytics project using Python, SQL &amp; Power BI to analyze hiring pipeline, time-to-hire &amp; recruiter performance. Includes ETL cleaning, SQL queries &amp; dashboard.

## 📊 Project Overview
Built an end-to-end recruitment analytics solution analyzing 100+ candidates to reduce time-to-hire and improve source effectiveness.

## 🔧 Tech Stack
- Python (Pandas, NumPy) for data cleaning
- SQL for hiring insights
- Power BI for visualization

## 📈 Key Insights
✅ Indeed fastest hiring source (20.1 days)
✅ Referral & LinkedIn highest quality
✅ Top performer: Priya (19 hires)
✅ 40% rejection due to skill mismatch
